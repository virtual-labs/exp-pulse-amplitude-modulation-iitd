Instructions for PAM / PWM / PPM Side-by-Side Comparison

  • Note: This page generates one message signal and one square carrier, then produces PAM, PWM, and PPM from them together, so you can directly compare the three.
  • Step 1: Use the sliders to set message frequency and carrier frequency.
  • Step 2: Click "Generate Comparison" to plot all three pulse modulation outputs stacked for the same message and carrier.
  • Tip: PAM varies pulse amplitude, PWM varies pulse width, and PPM varies pulse position -- all three carry the same message information in a different pulse parameter.
